# Store illustrations — version 2

Privacy-safe illustrative recreations based on the three user-provided reference screenshots. These are not live screenshots. All visible names, avatars, work item IDs, project names and task content are fictional.

Upload these 1280×800 PNGs separately in Partner Center → Store listings → Edit details → Screenshots:

1. `01-work-item.png`: location of the Copy task command in an open work item.
2. `02-pull-request.png`: copy action alongside work items linked to a pull request.
3. `03-project-labels.png`: compact project labels and the current-project star in Add link.

Created with the built-in image generator from screenshot references. Prompts requested the reference layouts in the dark Azure theme, replacement of all identifying data, English demonstration copy and an explicit fictional-data footer. Images were resized to 1280×800 for the store. Originals are retained in the session generated-images directory.

The previous `render-demos.ps1` script renders the older illustrations, not this set. The extension package does not include these store images.
