# Histórico de versões

Os commits de 1.1.0 a 1.2.3 foram reconstruídos em sequência a partir dos ZIPs preservados. O código de cada tag corresponde aos arquivos daquele pacote; os READMEs históricos foram escritos retrospectivamente. As datas dos commits representam essa organização do histórico, não datas de aprovação na loja.

## 1.2.3

- Caixa de ferramentas e símbolo ampliados para ocupar melhor o espaço do ícone.
- Ícone do painel ampliado para 56 px.

## 1.2.2

- Aplicação do ícone de caixa de ferramentas com símbolo do Azure DevOps.

## 1.2.1

- Seletor de idioma no painel, salvo localmente.
- Modo automático baseado no navegador, com opção manual.

## 1.2.0

- Interface em português (Brasil/Portugal), inglês, espanhol, francês, italiano, alemão, japonês, coreano e chinês simplificado.
- Catálogos locais, inglês como fallback e testes de traduções.

## 1.1.4

- Nome alterado para Toolkit for Azure DevOps.
- Preparação das primeiras imagens demonstrativas com dados fictícios.

## 1.1.3

- Nome intermediário Picolii Toolkit for Azure DevOps.

## 1.1.2

- Etiquetas de projeto com largura automática, compactas e com tooltip completo.
- Estrela preservada para indicar o projeto atual.

## 1.1.1

- Melhoria inicial de legibilidade das etiquetas de projeto.
- Versão instalada e verificação de atualização no painel.
- Instruções para atualizar a instalação local sem remover a extensão.

## 1.1.0

- Projetos dos resultados de Add link consultados em lote na API da organização.
- Etiquetas e destaque do projeto atual sem reordenar opções.
- Cache em memória, proteção contra respostas atrasadas e linhas recicladas.
- Painel com ativação independente dos três módulos.
- Leitura atualizada de títulos e tags.

## 1.0.2

- Correção de duplicação do botão em barras de comando aninhadas.

## 1.0.1

- Botão de cópia em páginas completas de Work Item, além dos diálogos.

## 1.0.0

- Migração dos scripts de cópia para extensão Manifest V3.
- Cópia de work items abertos e vinculados a pull requests.

## Documentação atual

- Repositório renomeado para Toolkit-for-Azure-DevOps.
- Política de privacidade atualizada para módulos, etiquetas e preferência de idioma.
- Imagens demonstrativas v2 recriadas a partir das referências do layout, com dados fictícios.
